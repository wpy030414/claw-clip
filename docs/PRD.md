# 产品需求文档（PRD）

> 鲨鱼夹 / ClawClip —— 本地优先的 Typora 级 Markdown 记事本。
> 本文定义「做什么、为谁做、做到什么程度算对」。技术实现见 [ARCHITECTURE.md](./ARCHITECTURE.md)，决策依据见 [DECISIONS.md](./DECISIONS.md)。

## 1. 产品定位

一个**纯本地**的 Markdown 记事本：数据全部存在浏览器 IndexedDB，无需登录、无需服务器、断网可用。编辑体验对齐 **Typora**（即时渲染 IR），界面遵循 **Material Design 3**，响应式适配桌面与移动。

一句话：**「打开即写、所见即所得、数据只属于你自己」的 Markdown 笔记本。**

## 2. 目标用户与场景

- 想在浏览器里快速记 Markdown 笔记、又不想把数据交给云端的人。
- 熟悉 Typora 的即时渲染体验、希望在 Web 端获得同等手感的人。
- 桌面（宽屏工作台）与手机（随手记）都要用、且数据在同一浏览器内一致的人。

## 4. 非目标（明确不做）

- ❌ **社交/博客**：无 author 笔名展示、无信箱(msg)、无成就(achievement)体系、无 firstCome——这些是旧版概念，本次收敛为纯记事本时砍掉。
- ❌ **云端同步/多端**：默认纯本地 IndexedDB；远程数据源仅保留接口形状（占位），不实现具体服务。
- ❌ **旧数据迁移**：全新数据模型，不写旧库(`ClawClip`)/旧 `.dat` 的迁移代码。
- ❌ **账号系统/协作编辑**。
- ❌ **PDF 导出**（Vditor export 主要出 md/html，PDF 走浏览器 print，非本次目标）。

## 5. 非功能需求

- **本地优先/离线**：所有资源（Vditor dist、Material Symbols 字体）自托管，运行时零公网 CDN 依赖（E2E 拦截 unpkg 验证）。
- **数据安全**：编辑不改 id；附件 blob URL 不落库（dehydrate 回 clawclip://）；object URL 及时 revoke 防泄漏。
- **性能**：列表页只读轻量投影 NoteSummary（不含 content）；附件独立 blob 表不拖慢列表。
- **健壮性**：命令式组件在 React19 StrictMode 双挂载下无僵尸实例/无泄漏（ADR-009）。
- **可测性**：数据层/store/hook/utils 高覆盖单测；编辑器/M3E 走 E2E。

## 6. 验收标准

功能语义**哲学层对齐**本 PRD + 高覆盖率测试通过，而非仅「能跑」：

1. **单测门禁**：`npm run test:unit` 全绿，覆盖 data/stores/hooks/utils，含旧「编辑=删旧建新」bug 回归。
2. **E2E**：`npm run test:e2e` 覆盖核心旅程——新建→编辑 Markdown→IR 渲染→自动保存→刷新持久化→原地编辑 id 不变→附件粘贴存库+渲染+刷新恢复→收藏→搜索→标签→明暗主题 token 跟随→自定义主色→响应式断点切换不丢状态→快捷键→离线自托管→StrictMode 切笔记无重复实例。
3. **type-check**：`npm run type-check` 零错误。
4. **离线**：DevTools 拦截 unpkg，公式/Mermaid/高亮/emoji 全走本地。
5. **CI**：push main 触发 build+type-check+test+部署，线上 `/claw-clip/` 可访问。
