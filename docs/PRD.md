# 产品需求文档（PRD）

> 鲨鱼夹 / ClawClip —— 本地优先的 Markdown 工作站。
> 本文定义「做什么、为谁做、做到什么程度算对」。技术实现见 [ARCHITECTURE.md](./ARCHITECTURE.md)，决策依据见 [DECISIONS.md](./DECISIONS.md)。

## 1. 产品定位

一个**纯本地**的 Markdown 文稿工作站，界面接近 Typora：

- **单主区 + 可收侧栏**：侧栏在「文档树」与「当前文件大纲」之间切换，可整体收起。
- 主区一键切换**编辑**（完整 Markdown 源码）与**浏览**（轻量 IR：隐藏非当前行标记、渲染样式，**仍可直接写**）。
- 用文件夹与文件组织文稿，所有内容存浏览器 IndexedDB，无需登录、无需服务器、断网可用。
- 预览/打印共用渲染结果，套用**可配置的印刷主题 CSS**，所见即打印。
- 支持「相当多扩展语法」：GFM 表格/任务列表/删除线、脚注、定义列表、上下标、`==高亮==`、KaTeX 公式、Mermaid 图表、代码高亮。
- **导入导出闭环**：MD / DOCX / PDF 均可导出；MD / DOCX / PDF 均可导回（PDF 为启发式还原）。
- 界面遵循 **Material Design 3**（M3E），响应式适配桌面与移动。

一句话：**「文件夹里的 Markdown 工作站：写、读、印、带走。」**

## 2. 目标用户与场景

- 需要在本机整理大量 Markdown 文稿（笔记、稿子、文档），并按文件夹归类的人。
- 需要把文稿交付成 Word / PDF，或把收到的 DOCX / PDF 转回可编辑 Markdown 的人。
- 需要先「看看印出来长什么样」、并对排版做自定义调整的人（论文/报告/打印稿）。

## 4. 非目标

- ❌ **云端同步/多端**：默认纯本地 IndexedDB；远程数据源仅保留接口形状（占位）。
- ❌ **账号系统/协作编辑**。
- ❌ **PDF 回导 100% 保真**：表格、图片、双栏版式只做启发式还原，以「可继续编辑」为目标。
- ❌ **旧数据迁移**：全新数据模型，不写旧库(`ClawClip`)/旧 `.dat` 迁移代码。
- ❌ **博客/社交/成就体系**：旧版概念已砍掉。

## 5. 非功能需求

- **本地优先/离线**：所有资源（字体、KaTeX、高亮样式）随构建自托管，运行时零公网 CDN 依赖。
- **数据安全**：编辑不改 id；附件正文只存 `clawclip://`，object URL 及时 revoke；Markdown 渲染关闭原始 HTML。
- **语义一致**：字数/摘要/标题派生在编辑器、列表、导出中同一套实现。
- **自动保存不可接管**：连续输入期间不写库，停止输入 700ms 后写一次；没有手动保存按钮或快捷键。
- **性能**：首屏不加载渲染管线与重型导入导出库；Mermaid/docx/mammoth/pdfjs 全部动态 import。
- **健壮性**：快速切换筛选丢弃过期查询响应；布局切换不丢未落库输入。
- **可测性**：数据层/store/hook/utils 高覆盖单测；核心旅程走 E2E。

## 6. 验收标准

1. **单测门禁**：`pnpm run test:unit` 全绿（data/stores/hooks/utils，含旧「编辑=删旧建新」bug 回归）。
2. **E2E**：`pnpm run test:e2e` 覆盖核心旅程——新建→编辑→浏览模式 IR 渲染→防抖自动保存→刷新持久化→原地编辑 id 不变→附件闭环→文件夹新建/过滤→侧栏大纲与收起→导入 MD→导出 MD/DOCX→PDF 打印→可配置打印主题→双形态断点切换不丢状态。
3. **type-check**：`pnpm run type-check` 零错误。
4. **离线**：无公网 CDN 依赖（字体与 KaTeX 自托管）。
5. **CI**：push main 触发 build+type-check+test+部署，线上 `/claw-clip/` 可访问。
